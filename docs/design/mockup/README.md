# IRCage mockup source

These are the source files of the approved clickable mockup
(https://claude.ai/artifact/SgvnSzqUnBcY89aH4mtT2m). They are written for the
design canvas, so `{{...}}` placeholders and `<sc-for>` / `<sc-if>` tags only
render there. Use them as the exact reference for colors, sizes, spacing,
radii and copy when building the Flutter screens.

| File | Screen |
| --- | --- |
| `Rooms.html` | Phone, Rooms home (light) |
| `Chat.html` | Phone, room chat in Comfortable style (dark) |
| `Private.html` | Phone, private chat with bubbles (light) |
| `Discover.html` | Phone, Discover rooms (dark), category filter and Join |
| `Mac-workspace.html` | Mac and iPad three-column workspace, light and dark tokens in the script block |
